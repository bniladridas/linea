Architecture

One Go process serves everything. The React frontend is compiled to static files and embedded via go:embed. No separate server for the UI.

Backend (backend/): Go server with HTTP API, SSE streaming, PostgreSQL or in-memory storage. CLI subcommands for daemon, TUI, migrations, health checks.

Frontend (frontend/): React app built with Vite. Compiled to dist/ and embedded into the Go binary. The web UI, macOS app, iOS app, and Android app all use the same API contract.

Providers: Gemini (primary). Cerebras, SambaNova, vLLM, MLX, and generic OpenAI-compatible (secondary). Ollama (local fallback). The runtime picks the first enabled provider in configured order.

Store (backend/internal/store/): Store interface with MemoryStore, PostgresStore, SyncStore (dual-write), RemoteStore (HTTP passthrough). The interface handles conversations, messages, users, API keys, workspaces, and background job records.

Agent (backend/internal/agent/): local agent runtime with guided, auto, and developer loop modes. Tools for file read, search, diagnostics, symbols, references, edit proposals, and command execution. Subagents for isolated work. MCP tools/resources/prompts/subscriptions through stdio servers. Background jobs for persistent autonomous loops.

CLI (linea): server, daemon, install, uninstall, status, tui, migrate, check, version. Same binary, different entry points.

Layer dependencies: frontend → API → services → store. The Go binary is the single source of truth. All clients connect over HTTP.
