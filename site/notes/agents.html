Agents

Agent loops read, edit, run, call MCP tools. Subagents handle isolated work.

Modes: guided pauses every step. auto applies safe edits. developer uses blocklist instead of allowlist. LINEA_AGENT_UNRESTRICTED=1 at startup enables full terminal autonomy with extended timeouts.

Commands: categories read, inspect, write, destructive. Auto-approve skips approval. Audit log records everything.

Subagents: built-in roles (review, search, docs, test). Custom subagents registered at runtime via POST /api/agent/subagents/register. Subagent plans run subagents in parallel.

Background jobs: persistent autonomous loops via POST /api/agent/background-jobs. Job state is persisted to the database and survives restarts.

New files: loops only edit files in diagnostic context. Use :proposal create <path> <content> → :proposal approve <id> → :proposal apply <id>.

Chat triggers: loops start for temp app keywords (page, app, preview). Background jobs don't block chat. 

# Start a loop
POST /api/agent/loops {"goal": "fix lint errors", "mode": "auto"}

# Create a proposal
POST /api/agent/edit-proposals {"path": "main.go", "content": "..."}

# Approve
PATCH /api/agent/edit-proposals/{id} {"status": "approved"}

# Apply
POST /api/agent/edit-proposals/{id}/apply

# Background job (persisted)
POST /api/agent/background-jobs {"goal": "run tests", "mode": "auto"}
POST /api/agent/background-jobs/{id}/cancel

# Custom subagent
POST /api/agent/subagents/register {"id": "my-checker", "tools": ["read_file"]}

# Subagent plan (parallel)
POST /api/agent/subagents/run {"goal": "review", "subagentIds": ["review", "docs"]}

# Unrestricted mode
POST /api/agent/unrestricted {"unrestricted": true}

# Command check
POST /api/agent/command-checks {"command": "make test"}

# Approve command
POST /api/agent/command-approvals {"command": "make test", "state": "approved"}

# Auto-approve categories
GET /api/agent/auto-approve-categories
PUT /api/agent/auto-approve-categories {"categories": ["read", "inspect"]}

# List state
GET /api/agent/subagents
GET /api/agent/subagent-plans
GET /api/agent/command-checks
GET /api/agent/command-approvals
GET /api/agent/command-runs

Config: LINEA_WORKSPACE_DIR, LINEA_AGENT_DEVELOPER_MODE, LINEA_AGENT_UNRESTRICTED, LINEA_LSP_COMMAND, LINEA_AUTO_APPROVE_CATEGORIES, LINEA_AUDIT_LOG_PATH, LINEA_COMMAND_ALLOWLIST.

Web UI: messages like "create a React app" start loops. Edit proposals shown for review.

TUI: linea -tui. Commands: :loop <goal>, :loop auto <goal>, :loop developer <goal>, :proposal create <path> <content>, :subagent [id] [query], :subagent plan <goal>, :agent, :checks, :approvals, :runs, :auto-approve <categories...>.
